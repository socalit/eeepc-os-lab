Full ASUS EeePC 1016P findings

The overall results, what actually worked, which Android builds failed, and the repeated limitations that showed up across nearly every test.

Hardware profile

LaptopASUS EeePC 1016P
CPUIntel Atom N455
Cores / threads1 core / 2 threads
Main limitationsWeak single-core CPU performance, 32-bit software and DRM limits, browser overhead, and outdated app support on old Android builds
Best current resultAndroid-x86 7.1 R5 with Smart Dock from F-Droid
Main lesson: this project stopped being about whether an OS could install. The real question was whether the laptop could still do useful things after booting. The CPU was the biggest wall.

What consistently failed

  • Spotify on 32-bit Linux because DRM support was not available in a practical way.
  • YouTube at anything above very low resolution because the Atom CPU hit its limit quickly.
  • Modern Android-x86 forks that expected more CPU than a single-core Atom could provide.
  • Upgrading from Android-x86 4.0 R2 EeePC to 7.1 R5 in place. It broke the OS and forced a fresh install.

Android alternatives that could not be fully tested

Bliss OS: loaded poorly, became unstable, and kept crashing. The CPU was not enough for it.
PrimeOS: booted but was unstable and too heavy to fully evaluate. The Atom N455 did not have enough processing headroom.
Phoenix OS: also unstable on this hardware. It crashed before useful app testing could be completed.

Best practical configuration

The best real-world setup was a clean install of Android-x86 7.1 R5 plus Smart Dock from F-Droid. That gave the laptop a more usable desktop-style launcher and let several key apps continue working.

Apps that worked on Android-x86 7.1 R5

  • Spotify
  • Discord
  • ChatGPT
  • VLC
  • RetroArch
  • FX File Manager
  • Chrome, with limitations

Apps or updates that failed

  • YouTube app no longer supported
  • Updated Chrome crashed
  • Netflix crashed
  • Plex crashed

Quick verdict

Best overall: Android-x86 7.1 R5

Best Linux feel: Linux Mint 32-bit

Most responsive Linux: MX Linux

Best hardware support: antiX

Best specialist use: Kali for terminal/network tools
