Android results on the ASUS EeePC 1016P

A breakdown of every Android-x86 build installed on the EeePC 1016P — from the EeePC-specific legacy image to modern desktop forks the hardware couldn't support.

Android summary: among Android options, 7.1 R5 had no real competition. The legacy 4.0 R2 EeePC build had hardware-specific shortcut integration but its app stack had aged out. The desktop Android forks — Bliss, PrimeOS, Phoenix — needed processing power this netbook doesn't have.

Android-x86 4.0 R2 EeePC

Fn shortcuts workToo outdated
  • Shortcut keys and volume controls worked well.
  • Browsers were several years behind current standards and most app APIs had moved on.
  • Nothing practically useful could run — the Android 4.0 app ecosystem dried up long ago.

Android-x86 7.1 R5

Best optionSpotify worksSome apps crash
  • Upgrading in place from 4.0 R2 corrupted the install — that path doesn't work.
  • Starting fresh from the 7.1 R5 ISO was the only approach that held.
  • Smart Dock, pulled from F-Droid, replaced the default tablet-style interface with a real desktop layout.
  • Chrome handled YouTube at 240p, which was the practical ceiling. The YouTube app itself is past its supported API version on this Android release.

Working apps on 7.1 R5

Usable set
  • Spotify
  • Discord
  • ChatGPT
  • VLC
  • RetroArch
  • FX File Manager
  • Chrome, with limitations and no current update path

Apps that failed on 7.1 R5

Crashes
  • Current Chrome builds crash on launch
  • Netflix fails immediately — no supported path on Android-x86 7.1
  • Plex crashes before reaching the library
  • YouTube app is past its API support window

Bliss OS

Too heavyCrashes
  • Never stabilized enough to test properly.
  • Setup was slow and the system crashed repeatedly before reaching a usable state.
  • Bliss OS targets hardware with real multi-core performance — the N455 isn't it.

PrimeOS and Phoenix OS

Too heavyUnstable
  • Neither could run stably on a single-core, 1.66 GHz processor.
  • Both crashed before any real app testing was possible.
  • Age isn't really the issue — these OSes assume processing headroom the N455 doesn't offer.
