Best result: Android-x86 7.1 R5 was the best practical option for this netbook. Spotify worked, Chrome could handle YouTube at 240p, and several useful apps still ran. The biggest overall limitation across the project was the Intel Atom N455 CPU with 1 core and 2 threads.

Linux results

Mint 32-bitMXantiXKali

Mint looked the most current, MX handled responsively despite its older look, and antiX fit the hardware well. Kali had a narrower use case here. Across all of them, media streaming ran into the same two walls: the processor and 32-bit DRM.

Main limitations discovered

  • Single-core performance: the N455 runs one core at 1.66 GHz with two threads — that ceiling touches everything.
  • Spotify needs Widevine DRM, which has no 32-bit Linux support. Every distro confirmed this.
  • Video playback topped out around 240p in Chrome; anything higher stalled.
  • Streaming apps requiring newer APIs — Netflix, Plex, and current Chrome builds — all crashed.
  • The EeePC-specific Android 4.0 build had native shortcut key support, but its software stack was too far behind to be practical.
