Main CPU bottleneck
Best result: Android-x86 7.1 R5 was the best practical option for this netbook. Spotify worked, Chrome could handle YouTube at 240p, and several useful apps still ran. The biggest overall limitation across the project was the Intel Atom N455 CPU with 1 core and 2 threads.

Linux Mint 32-bit gave a modern desktop, MX felt dated but responsive, antiX had good hardware support, and Kali made sense only as a terminal and network-tools box. DRM and CPU limits hurt media use across the board.

Working apps on Android-x86 7.1 R5

  • Spotify
  • Discord
  • ChatGPT
  • VLC
  • RetroArch
  • FX File Manager
  • Chrome, with limitations and no current updates

Main limitations discovered

  • Atom N455 CPU is the main bottleneck: 1 core, 2 threads.
  • Most 32-bit Linux installs hit DRM issues for Spotify.
  • YouTube was limited to about 240p and often buffered.
  • Updated Chrome, Netflix, and Plex crashed on Android-x86 7.1 R5.
  • The old Android-x86 4.0 R2 EeePC build had working shortcuts but was too outdated to use.
